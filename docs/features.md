## Getting started and the shared library

- **First vocabulary setup wizard.** When a new account opens the training page with no vocabulary, a wizard replaces the empty state. **Step 1** picks the HSK standard: **HSK 3.0** (2025 syllabus, default) or **HSK 2.0**, with live word counts from the library. **Step 2** picks your level band (Beginner, Intermediate or Advanced) and the level to start with. If you start above the lowest level, choose what happens to the words below it: *Mark as known* (default), *Quick review* or *Learn them too*. **Step 3** is optional and appears only when the library has topic lists (tags named `topic-<name>`, made by `import-topics`). Pick topics to add their words on top of your HSK list, or *Skip*. A topic word that sits in an HSK level you marked as known stays known. **Step 4** sets your pace (5, 10, 20 or 30 new words per day), the meaning languages (English, Deutsch or both), gamification, and automatic audio. The wizard saves these choices as your settings and imports the lists, and the first new-word introduction follows. *Import my own list instead* opens the **shared library** screen. It lists every HSK level and topic, and you can combine them. *Meaning in* picks the translation languages, and *Words tagged with* chooses **Any tag** (every word with at least one selected tag) or **All tags** (only words that have every selected tag, for example HSK 1 + Food). Each imported word gets the tags you selected. If you already have a word, the import does not add it again. It only adds the tag of the new list to your word. A word you mark as **known** is never a quiz prompt and never counts as a new word, but it stays in your vocabulary, in the mismatch detection, and as a wrong-answer choice. In **Vocabulary**, use the *Known words* filter to list them, and the *Mark as known* / *Back to training* button in the edit form to change a word. Except for *Mark as known* and *Quick review*, every import leaves the imported words unseen so they are introduced one at a time through the normal daily new-word cap, just like a manually-added word — a bulk import never floods the first session with dozens of never-practiced words at once. **Vocabulary → Import** keeps its own tag picker. A list import runs as a background job, so you do not wait for a long list (for example thousands of HSK words). The import adds words in list order, in chunks of 200. Training starts as soon as the first chunk is in. A banner above the card shows the progress ("Importing… 200 of 500 words") until the job ends. **Vocabulary → Import** shows the same progress. Jobs are stored in the database. If the server restarts during an import, it continues the job at the next start. Words that are already imported are not added again. The counters of a resumed job (imported, tagged, skipped) then describe only the last run. `POST /api/import` returns `202` with the queued job. `GET /api/import/jobs/{id}` returns its status and progress, and `GET /api/import/jobs` returns your queued and running jobs. Translations that library lists take from CC-CEDICT/HanDeDict are marked as dictionary translations (`cedict`), with their frequency rank, so "Hide rare translations" applies to them. Words you imported before this change keep their old source.
- **Shared library, no copies.** An imported list does not copy the words and their translations to you. You get a reference to each library word, and the translations come from the library (CC-CEDICT/HanDeDict) in your primary and secondary language (**Settings**). When the dictionaries get an update (`make refresh-library`), you see the new translations at once. Your own changes stay private: added and deleted translations and your pinyin. **Vocabulary → Import** shows the translation languages and a **Your lists** box with every list you imported: *N new · Update* adds words that the library added to the list later, and *N removed earlier · Include again* adds back words you deleted (an update never adds them by itself). Library updates also reach words you edited: your added and deleted translations stay on top of the new library version. When a word differs from the library, its edit sheet shows **Reset to library**. It first lists what the reset changes (translations it removes, translations it brings back, the pinyin), and applies it only when you click **Reset**. Your progress and tags stay. Words you add by hand, by CSV upload or as automatic sub-words also become library references when CC-CEDICT/HanDeDict has them (the library adds a word it does not have yet). Translations you type that the library does not have stay yours; a sentence without a dictionary entry stays your own word. The shared library user is read-only in the UI. See [ADR-0005](adr/0005-shared-library-with-per-user-references.md).

- HSK word lists for the shared library: HSK 2.0 (tags `hsk2-1` to `hsk2-6`) and HSK 3.0, 2025 syllabus (tags `hsk3-1` to `hsk3-6`, and `hsk3-7` for the combined levels 7–9). See [HSK vocabulary import](data-import.md#hsk-vocabulary-import).

## App shell

- **App shell and UI language.** On screens 880 px and wider, a sidebar holds the navigation in three groups: *Practice* (Train, Pinyin), *Library* (Vocabulary, Mnemonics, Mismatches) and *You* (Stats, Settings), with *Report an issue* and *Sign out* at the bottom. On narrower screens, a top bar shows the page title and a bottom tab bar shows *Train*, *Vocabulary*, *Stats*, *Report* and *More*. *More* opens a sheet with Pinyin, Mnemonics, Mismatches, Settings, Fullscreen and Sign out. The *Report* tab is shown only when issue reporting is configured. Otherwise the tab bar has four tabs. You set the UI language (English, Deutsch, 中文) in **Settings → Languages → App language**. The server stores it with your settings, so it applies on every device. The browser keeps a copy so the page shows the right language at once. If you picked a language on the login page before, the app saves that choice to your settings the first time you sign in.
- **Landing page for signed-out visitors.** The root page (`/`) shows the value proposition — spaced repetition, native audio and pinyin drills, character mnemonics — next to the sign-in/register card, with a "Create free account" call to action. The page carries SEO and Open Graph meta tags so it can be found and shared.
- **Try-before-signup demo quiz.** Signed-out visitors can answer five fixed demo cards (Chinese + pinyin → English) directly on the root page, with no account. Answers are checked server-side with the same flexible matching logic as the real quiz, wrong answers reveal the accepted translations, and finishing the demo leads to a "Create free account" prompt. The endpoints (`GET /api/demo/cards`, `POST /api/demo/answer`) are public, stateless, and store nothing.
- **Credits and licenses.** The `/credits` page lists every dictionary, word list, font and library that the app uses, with its source and license. You can open it without an account, from the landing page footer and from the bottom of **Settings** (next to the Impressum). The page is in English, German or Chinese, and has its own language selector. Each license link of a file that the app includes opens the full license text (`/licenses/<file>`).

- **Compact mobile layout.** On small screens, the nav bar and quiz card use tighter padding and margins so more of the card fits above the on-screen keyboard.
- **Fullscreen / installable app.** When the browser supports the Fullscreen API, a ⛶ toggle button appears in the training session bar, and the phone *More* sheet has a *Fullscreen* row on every page, letting you hide the browser chrome with a tap (browsers only allow entering fullscreen from a user gesture, so it can't happen automatically on page load). The app also ships a web app manifest, so you can "Add to Home Screen" on mobile for a standalone, chrome-free experience — installing it hides the fullscreen toggle, since there's no browser chrome left to hide.

## Quiz modes

- The app has eight quiz modes. You can pick a mode, or let the app pick one at random.
  - **English → Chinese**
  - **Chinese → English**
  - **Chinese (no sound) → English**. This mode is the same as Chinese → English, but it hides the 🔊 play button and never auto-plays audio. Use this mode to drill visual hanzi recognition without an audio cue.
  - **Chinese + Pinyin → English**
  - **Voice → Translation**. The Chinese character is hidden; only the audio plays. You must type the translation from memory. Audio always plays automatically when a card appears. If your device has no speaker, enable "Voice not available" in Settings to fall back to showing the Chinese text (equivalent to Chinese → English). If you type the meaning of a different word with the same pinyin and tones (for example "foot" (脚 jiǎo) for 角 jiǎo), the result screen "Same sound, other word" shows the word you typed and a button to play the sound again. It does not show the meaning. Type the meaning of the word you heard. A correct second answer counts as correct. The app finds the other word only in the words you already trained.
  - **Voice → Chinese**. The word and its meaning are hidden; only the audio plays. You must type the Chinese characters. If you type a different word with the same pinyin and tones (a homophone, for example 她 for 他), the result screen "Same sound, other word" shows the meaning of the word you heard and lets you type again. A correct second answer counts as correct, like on the "Right meaning, other word" screen. The app gets the pinyin of the typed word from your vocabulary, else from the dictionary.

  When you skip a voice card, the app asks if voice is not available. If you answer yes, the app asks the same word again at once instead of skipping it: a *Voice → Translation* word as *Chinese → Translation*, a *Voice → Chinese* word as *Translation → Chinese*. Later voice cards in the same session use these fallback modes too.
  - **Progressive**. This mode picks the quiz direction based on your learning progress.
  - **Cycle**. This mode rotates through a sequence of directions that you configure for each word.

- The app uses [SM-2 spaced repetition](https://www.supermemo.com/en/blog/application-of-a-computer-to-improve-the-results-obtained-in-working-with-the-super-memo-method). Words you get wrong appear more often. The app schedules correct answers further into the future.

- Due-date and correct-answer scheduling include a small random jitter. This shuffles cards and avoids repetitive review patterns.

- **Daily new-word cap.** This setting limits how many new words the app introduces per day. The default is 5 words, and you can configure it with `MAX_NEW_WORDS`. Once you reach the cap, the app serves only already-seen cards for the rest of the day. The training page shows a "New today: X / Y" counter in the stats bar.

## Training screen

- **Training session bar.** A sticky bar on the training page shows "X of Y today" (answers today against answers plus what is still due) with a progress bar. X counts every answer: words, components and mnemonic scenes. *Accept as correct* changes the wrong answer to a correct answer, so the card counts one time. The all-done screen shows the same number of answers. The bar also shows the due and new-word counts, the session chip ("Mode · Level"), and buttons for auto-play and fullscreen. The session chip opens the **session sheet** (a bottom sheet on phones, a centred dialog on desktop) with the quiz mode, level, meaning languages, mnemonics, components and tags. Mode, level and tag changes apply when you close the sheet. The question card does not show the word's tier chip, so it does not hint at how well you know the word. Result screens show the word, a folded **More info** box (more meanings, *Measure word* from `CL:`/`ZEW:` entries, *Example* from `Bsp.:` entries), the tier chip, the next due date, *Edit*, *Flag for review* and *Next*. When the word or component is already flagged for review, the button shows *Flagged* in orange. Click it again to remove the flag. When your answer is the meaning of another word, the result shows a mix-up layout: the asked word, "you typed … which is", and the other word with the typed meaning highlighted. Word cards in the learning phase show 3 streak dots when gamification is on. The character breakdown and the mnemonic scene stay available as folded sections under the result.
- **Auto-play sound.** A 🔇/🔊 toggle button sits in the training session bar, next to the fullscreen button. This setting is off by default. When you turn it on, the app automatically plays the Chinese pronunciation whenever it shows a new word, component prompt, or introduction. The app never auto-plays the prompt in *Translation → Chinese* mode, because that would reveal the answer before you've answered — and it never auto-plays *Chinese (no sound) → English* prompts, for the same reason that mode hides the play button. Once you submit an answer, if the pronunciation wasn't already auto-played on the question screen (e.g. because it was withheld to avoid revealing the answer, or skipped due to the pinyin-blur setting), the app reads it out on the result screen instead — for both word and component cards. By default the setting does not persist. It resets to off when you reload the page. To start every session with auto-play on, turn on **Settings → Audio → Always play audio automatically**. You can still switch the button off on the training page. Only one clip plays at a time: a new clip stops the previous one, and the app stops the sound when it shows the next card. A tap on 🔊 while the same clip still loads does nothing, so the clip plays only one time.
- **Auto-focus of the answer field.** When a card appears, the app can put the cursor in the answer field on its own. On a phone, this opens the on-screen keyboard and covers the card. **Settings → Keyboard** has two switches: *Focus the answer field automatically on desktop* (on by default) and *… on mobile* (off by default). Touch devices (coarse pointer) use the mobile switch. All other devices use the desktop switch. The switches also apply to the answer field on the pinyin listening page, to the retype fields (after a wrong answer and for a new word), and to the input that asks which word you meant.
- **Enter continues.** On the training page, Enter does the main action of the screen: *Next* on the result screen, *Continue* on the tier celebration, *Got it* on a new word or component (when the button is available), and *Try again* on the error card. Enter does this also when the focus is on a different button, or on no element. When the cursor is in a text field, Enter does the action of that field.

- **Blur pinyin.** This optional setting is in Settings → Training Mode → Quiz Display. It blurs the pinyin hint on quiz cards, so you cannot read it at a glance. Tap or click the hint to reveal it. The hint blurs again on the next card.
- **Bucket growth indicator.** The result screen shows one growth icon (🌰🌱🌿🌳🌸) for each accuracy tier: New, Struggling, Learning, Practicing, or Mastered. The icon marks the current tier of a word, HMM entity, or component, on both correct and wrong answers.
  - **Celebrate bucket changes** is an optional setting, off by default, in Settings → Training Mode → Quiz Display. When a correct answer advances a word's tier, this setting shows a "Level up" screen before the result screen. The old tier's icon turns and fades into the new one in a tile that changes colour, then a ring pulses once. The screen shows the word and the old → new tier chips.

- **Sentence fill-in-the-blank.** An optional training mode, off by default, in Settings → Training Mode → Quiz Display ("Sentence fill-in-the-blank" + a frequency percentage). Tag a zh word with a tag that ends in `_s` (for example `hsk2-1_s`) to mark it as a sentence. The tag is in the same tag group as the list it belongs to (`hsk2-1_s` is in the HSK group), so in a training filter the sentences are an addition to the list (OR), not a restriction (AND). When enabled, the training page occasionally shows one of your sentences with one word blanked out instead of a plain word card — either the Chinese word is blanked (translation shown as context) or a word inside the sentence's translation is blanked (Chinese shown as context), following the direction of your training mode, the same as a word card. This includes the Cycle step and, after a wrong answer under *advance only on success* or *advance only if known*, the same direction again. A mode that asks for Chinese (also *Voice → Chinese* and the pinyin hint) blanks the Chinese word. All other modes blank the word in the translation. A sentence only becomes eligible once every word it contains (punctuation aside — commas, quotation marks, etc. are skipped) has been reviewed at least once, and the app always blanks whichever of those words is next due, so the mode reinforces words you already know in context. A sentence must have at least two words, so at least one other word always shows next to the blank. A sentence that CC-CEDICT or HanDeDict has as one entry (for example 从来) is a word, not a sentence, and the app does not use it. If the translation side has no blank for the word (the word's translation is not in the sentence translation, or it is the full sentence translation), the app shows a normal word card instead, so the direction does not change. The answer field tells you the language to type: Chinese, English or German. Answering updates that word's own SM-2 progress, the same as answering it in a normal quiz card would. The result screen shows the full Chinese sentence above the answer word, with the answer word marked, the sentence pinyin (if the sentence has pinyin), the sentence translation and a speaker button that reads out the sentence. When auto-play is on, the result screen reads out the full sentence. If you type another word with the same meaning, the "Right meaning, other word" screen shows the shared meaning and the other meanings of the blanked word, and lets you type again.

- Every Chinese word has a 🔊 read-aloud button. The button plays a cached MP3 file, generated with Microsoft Edge neural TTS, which is built into the binary. If this fails, the button falls back silently to the browser's Web Speech API.

## Answers

- **Answer language in the input.** On word and component cards that ask for a translation, the answer field says which language to type, for example *Type German*. It names your primary language if you train with it, else the first selected language. Other selected languages are still accepted.
- **Flexible answer matching.** Parenthesized segments are optional: `(das) Essen` accepts `Essen`. Fullwidth Chinese parentheses `（）` work the same way: `还（动词）` accepts `还`. Slash- or comma-separated alternatives are each valid: `Essen / Gericht` accepts `Essen` or `Gericht`, and `topic, item` accepts `topic` or `item`. Typing all slash-separated parts in any order also works: `Wohnzimmer / Schlafzimmer` accepts `Schlafzimmer / Wohnzimmer`. The same applies to mnemonic names on HMM cards.
- **Wrong-answer review.** On a wrong answer, the app shows what you typed next to the correct Chinese text, pinyin, and translations. You can add your answer as an accepted translation with one click. In *Translation → Chinese* mode, the app also shows pinyin beside your typed Chinese answer, so you can see how it is pronounced. If you have two active learning languages (primary and secondary), a language picker lets you choose which language the new translation belongs to. The picker defaults to your primary language.
- **Accept as correct.** If a wrong answer was a typo, click "Accept as correct" to restore your pre-answer SM-2 progress. The app then counts the attempt as correct, with no penalty. You can configure this behavior in Settings: never, on 1-character typos (the default), or always.
- **Retype on wrong answer.** This optional 3-way setting is off by default, in Settings → Training Mode → Wrong Answer Retry: **Off** continues immediately; **Only what was tested** requires retyping only the field(s) the card's direction actually asked for (e.g. just the translation for a Chinese → translation card, just the Chinese word for a translation → Chinese card); **Chinese and translation** always requires both, regardless of direction. Whichever field(s) are required, the "Next" button stays disabled until they check out. The fields show their hint inside the input ("Type Chinese", "Type German"), not as a label above it. Component (hanzi) cards use the same gate, also on the "That's a different word" screen: with **Only what was tested**, you retype one meaning of the component. The "Accept as correct" and "Add as translation" shortcuts stay available alongside the retype fields and, like "Next" when the gate is off, still advance straight to the next card when clicked — accepting the answer already confirms it, so no retype is required in that case. This mirrors the same required-retype pattern used for the new-word introduction screen.

- **Confusion tracking.** If your wrong answer is a valid translation of a different, known word or hanzi component, the app records it as a confusion pair. This works in all quiz modes, including component quizzes. The result screen shows it right away as a mix-up (the asked word, then the other word with your typed meaning highlighted), and you can see the full history on the `/mismatches` page. There, each pair is a card with both words, the quiz mode, the last time you confused them and a count pill (red from 5 mix-ups). You can sort the cards by *Most often* or *Most recent*. Its translation list respects translation ranking the same way as the main result box: capped to your configured max, with the rest collapsed into a "More info" toggle.

## Translations on cards

- **Translation ranking.** An optional setting in Settings → Training Mode → Quiz Display ("Hide rare translations during training") — preselected for newly registered users, with max translations shown defaulting to 4 (existing users keep whatever they already had, off by default). CC-CEDICT/HanDeDict-derived translations are ranked by how common each gloss's rarest word is, using bundled English/German word-frequency lists (from [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords), same source as the existing Chinese frequency list). When enabled, only the top N translations per language (configurable) are shown directly on quiz cards; translations you added or edited yourself are prioritized into that visible set first, but still count against the cap like any other translation. Anything over the cap is collapsed into a "More info" toggle right below the visible list (both on the question screen's translation hint and on the answer-result screen), so you can still see it on demand instead of it being silently dropped — and it always stays a valid answer, cap or no cap. On the *Translation → Chinese* question screen specifically, and in the gray question box on the "Ambiguous" screen (where you still have to type the Chinese answer), CEDICT/HanDeDict example-sentence annotations are left out of "More info" entirely (rather than just collapsed), since an example sentence can contain the Chinese answer you're about to type; they still show in "More info" everywhere else (new-word introduction, answer-result screen). A separate "Also hide translations with no frequency data" toggle controls whether a gloss with no match in the frequency list counts as low-priority (collapsed if over the cap) or is prioritized into the visible set like your own translations — off by default. A "My own translations" dropdown (only active while ranking is on) sets where your own translations go: "Show first" (default) orders them your own → no frequency data → ranked; "Show last" orders them ranked → no frequency data → your own, so your own translations can end up in "More info" when the cap is reached. Within each language's shown list, a trailing short HanDeDict/CEDICT part-of-speech tag like `(S)` or `(V)` is hidden, and an exact duplicate gloss (case-insensitive, after that tag is hidden) is collapsed to a single entry — this is display-only and does not change the cap, the "More info" list, or which answers are accepted.
- **Pinyin-only translations are hidden.** Some dictionary glosses are only the pinyin of the word, for example the surname gloss "Nan (Eig, Fam)" for 南 nán. Training does not show such a translation, and does not use it as the *Translation → Chinese* prompt or as a match-game answer. The check ignores case, tone marks, spaces and parts in brackets. If this translation is the only one in a language, training shows it. The translation stays a valid answer, and the vocabulary editor still shows it.

## End of the day

- **Come-back-tomorrow summary.** The "All done for today!" screen shows your current day streak (consecutive training days) and how many reviews come due tomorrow, so the spaced-repetition loop is visible from day one. When at least one word moved into a better proficiency bucket today, the screen also shows how many — computed by comparing today's bucket snapshot in `daily_stats` against the closest prior day's snapshot and summing the positive deltas across the struggling/learning/practicing/mastered buckets (the "new" bucket is excluded, since growth there reflects new words being added, not existing ones improving).
- **Review today's mistakes.** When you answered words wrong today, the "All done for today!" screen shows a *Review today's mistakes (N)* link. It opens a list of these words with pinyin and translations. A word is in the list when its last wrong answer was today (UTC day, the same day as the daily stats), also when you answered it correctly later. Known words are not in the list. *Train them again now* makes all these words due now, and training continues with them. Their SM-2 values (interval, ease, counters) do not change. After *Train them again now*, these words leave the list. A word comes back into the list only when you answer it wrong again.
- **Difficult-words drill.** Once you review everything due, the "All done for today!" screen offers a "Drill my hardest words" option. Tick the option and pick an amount to flag that many of your hardest words. The app picks about half by lowest accuracy and half by lowest ease factor. The app serves flagged words on demand, regardless of their due date, until you answer each one correctly. A correct answer clears the flag. A temporary "Difficult words" pill in the filter bar shows that the drill is active and shows how many words remain. Click the pill to exit the drill early.

## Vocabulary

- Add vocabulary with Chinese characters, pinyin, and one or more English translations.
- The app supports N:N word relationships. The same English or Chinese word can appear in more than one entry.

- **Vocabulary page.** The header shows "N words · M due today" with *Import*, *Add word* and a *⋯* menu (*Download vocabulary*, *Upload CSV*, *Manage tags*). A toolbar switches between *Words* and *Components*, has a search field and filter chips (*All*, *Due today*, *Due tomorrow*, *Needs review*, *Known*, *Failed last review*, *Hide unseen*, *Missing DE*/the secondary language). *More filters* adds the level and tag filters, *Missing EN/DE* and the sort order (Chinese, pinyin, English, German, level or due date, ascending or descending). Each word is one row: Hanzi, pinyin, badges, one line per meaning language ("missing" in red when a language has no meaning), the tier chip and the due date. Tap a row to edit it in a sheet (bottom sheet on phones, dialog on desktop) with *Mark as known*, *Reset progress*, *Delete*, *Reset to library* (only for a library word you changed), and folded *Mnemonic* and *Components* sections. Pagination (20/50/100 per page) sits under the list.

- Vocabulary management: add, edit, delete, search, paginate, and sort by any column. Searching ranks exact matches (Chinese text, pinyin, or a translation) above partial matches, ahead of the chosen sort. The app shows SM-2 progress per word.
- **Reset a word.** In the Edit Word form, a **Reset** button appears for any word you've already started training. It clears the word's SM-2 progress back to unseen — removing it from every bucket — so it is reintroduced as a brand-new word.

- **Tags.** You can assign tags to vocabulary words, for example `hsk3-1`, `topic-food` or `lesson1`. You can filter by tag on the vocabulary list, the training page and the stats page. An autocomplete input creates tags on the fly, and the app removes unused tags automatically.
  - **Tag groups.** Tags with the same prefix (the text before the first `-`) form a group, for example `topic-food` and `topic-travel`. All `hsk…` tags (HSK 2.0 and HSK 3.0) are one group. All tags without `-` are one group. When you select more than one tag, a word must have at least one selected tag of each selected group (OR in a group, AND between groups). Example: `hsk3-1` + `hsk3-2` + `topic-food` shows words from HSK level 1 or 2 that also have the tag `topic-food`.
  - The training session sheet and *More filters* in **Vocabulary** show one row per group (*HSK*, the prefix, *Other*). An ⓘ button next to each tag field (session sheet, vocabulary filter, word edit sheet, CSV upload, import, *Manage tags*) shows this rule.

- **Auto-translate.** A "Translate" button in the Add/Edit Word form detects direction automatically: enter Chinese to get the translation and pinyin filled in, or enter the translation to get Chinese and pinyin back. It first tries a free local dictionary lookup (see "Free dictionary lookup" below); for the Chinese→translation direction, if that finds nothing it falls back to DeepL when configured (plus/admin accounts or a personal DeepL key). The reverse direction (translation→Chinese) is DeepL-only. The app generates pinyin locally with [go-pinyin](https://github.com/mozillazg/go-pinyin). Generated pinyin preserves `()`/`（）` brackets from the Chinese text, so a word like `过 (动词)` gets pinyin `guò (dòng cí)`.
- **Pinyin auto-fill in the Add/Edit Word form.** As you type in the Chinese field, the app fills the Pinyin field automatically once you pause. If the Pinyin field is already non-empty (auto-filled or hand-edited), the app doesn't recompute it on every keystroke — only after you stop typing for 3 seconds or move focus out of the Chinese field, and only after confirming if the recomputed value differs from what's there.

- **Free dictionary lookup.** The "Translate" button in the Add/Edit Word form first tries a free, ungated exact-match lookup against the imported CC-CEDICT/HanDeDict data before falling back to DeepL — so it now works for every user, not just plus/admin accounts or a personal DeepL key. Each dictionary sense fills its own translation field: definitions are split at `;` and `,` (HanDeDict separates senses with commas), but not at commas inside brackets such as `(in the capacity of, as)`. Sub-words created from the dictionary use the same split, and a schema migration splits existing comma-joined dictionary translations the same way (translations you entered yourself stay unchanged).

- **CSV upload.** In **Vocabulary**, the upload button imports a CSV file. The header row is required. The first column is `chinese`. An optional second column is `pinyin`. Every other column is a language code (`en`, `de`, …). Separate several translations in one cell with `;`. An optional column `source` sets where the translations of a row come from: `user` (your own translations, always shown) or `cedict` (dictionary translations, which "Hide rare translations" can hide during training). A row with another `source` value is skipped. The upload dialog has a choice for the rows that have no value, or when the file has no `source` column. The default is `user`. A row for a word that you already have replaces its translations, and it uses the same source rules.

- You can bulk-import vocabulary from a structured text file. See [Bulk import](data-import.md#bulk-import).

- **Generate sentences.** In **Vocabulary → ⋯ → Generate sentences** (or the *Sentences* tab of the sheet), the AI writes example sentences from words you already know. Select tags (tag groups as in the word filter; no tag means all your words) and the number of sentences (5, 10 or 20), then click **Generate**. A word you know is a word you reviewed at least once, the same rule as for sentence fill-in-the-blank. Each sentence contains at least one focus word: a known word of the selected tags. **Focus words** sets which words the app takes first (at most 30): *All words* (random order), *Hardest words* (lowest accuracy first, then lowest easiness, the same rule as the difficult-words drill; words with fewer than 3 answers come last), *Mix-ups* (only words that you mixed up with another known word, most mix-ups first; the AI puts both words of a pair into one sentence where it is natural) or *Most frequent words* (most common in Chinese first, from the bundled frequency list; words that are not in the list come last). When **Cover all words evenly** is on (default), the app first takes the words that occur least in your sentences, and the focus choice only sets the order among them. So all words get about the same number of sentences over time, and the words of your choice get them first. When it is off, the app takes the words only in the order of the focus choice, so these words get new sentences in each run. The other words of a sentence must also be words you know. The app removes a sentence that has a word you do not know or that you already have, so every sentence can show in fill-in-the-blank at once. The pinyin comes from your own words. The translations are in your primary and secondary language. You can change the pinyin and the translations, and clear the check box of a sentence you do not want. Then type an existing or a new tag and click **Add N selected**. Check **Start training immediately** next to the button to put the sentences into training at once, the same as the toggle in the *Add word* form. The app adds `_s` to the tag name if it does not end in `_s` (`daily` becomes `daily_s`), because only a `_s` tag marks a sentence. The sentences are your own words, like a word you add by hand. Requires a plus account or your own LLM key (Settings → API Keys).

## Characters and components

- **Character breakdown.** On the training screen, a collapsible "Character breakdown" block appears below each Chinese character. Click it to reveal the radical, definition, etymology hint, and component parts with their meanings. This data comes from [makemeahanzi](https://github.com/skishore/makemeahanzi), imported with `service/cmd/import-hanzi`.
- **Word/component cross-reference.** Some characters are tracked both as a full vocabulary word and as a standalone component (radical) — they have independent SM-2 progress, since drilling a radical separately from the word it appears in is intentional. To make this visible: on the `/vocab` page, the Words and Components tabs show a small "also a component" / "also a word" badge on entries that exist on both lists; during training, a word card's mode label gets an "Also a Component" suffix (mirroring the component card's existing "Component & Word" label) when applicable.
- **Sub-word detection.** When you add a multi-character word (for example 踢足球, "to play football"), the app segments it against an imported CC-CEDICT/HanDeDict dictionary (`service/cmd/import-cedict`) using forward maximum-match. Characters not absorbed into a recognized sub-word (e.g. 踢, "to kick") are trained as components automatically, alongside their radicals. Recognized multi-character sub-words (e.g. 足球, "football") are automatically created as new, inert vocabulary words — never force-acknowledged, so they queue into the same daily new-word cap as any manually-added word.

- **Component training coverage target.** Settings (`/settings`) has a "Component Training" card with a target word-coverage percentage (0–100%, default 0 = no filtering). When a new word starts training, only enough hanzi components are added to your training rotation to cover that share of your current Chinese vocabulary — greedily picking, each step, whichever not-yet-trained component unlocks the most words you haven't covered yet, until the target is reached (or every qualifying component is exhausted). The card shows only a summary, not a full component list: how many components you are already training right now (independent of the previewed target); how many of every qualifying component would be added to reach the currently-typed target, both as a count and as a share; and, of your already-trained components, how many exceed what's needed for that target and so would not have been added if you were starting fresh at this level — informational only, since components already being trained are never removed by this setting; it only affects future additions.

## Stats

- **Training stats.** The app tracks daily progress: attempts, mistakes, accuracy, words known, new words learned, and your best correct streak. The `/stats` page shows a Chart.js bar or line chart of your full history, and a table of the last 14 days.
- **Word-level statistics.** The `/stats` page has four tabs (Words, Pinyin, Components, Mnemonics). The Words tab starts with four tiles: answers today (with mistakes), 14-day accuracy (with the change vs the previous 14 days), words in training (with the count due today) and the day streak. When gamification is off, the last tile shows the training time of the last 14 days. Below the tiles: the training history chart, **Levels** (a stacked bar and one row per level, including an **Unseen** row for words you have not practiced yet), the words due in the next days, your hardest and most-practiced words, a **Level history** chart and a folded "Last 14 days" table. Levels and due dates can be filtered by tag.
- **Due date distribution.** The `/stats` page shows a bar chart of how many words are due on each day over the next 30 days. Tag filter chips let you narrow the view to specific word groups.

## Pinyin listening

- **Pinyin listening training.** The `/pinyin` page trains tone and sound discrimination. You hear a pinyin syllable and identify it: by multiple choice in the learning phase, or by typing an answer, for example `ba1`, in the review phase. SM-2 spaced repetition tracks your progress per sound, across about 1,600 syllable and tone combinations from the public-domain [mp3-chinese-pinyin-sound](https://github.com/davinfifield/mp3-chinese-pinyin-sound) collection. You can filter by consonant group, for example b/p/m/f or zh/ch/sh/r. The page also tracks confusion between commonly mixed-up sounds. A sticky bar shows how many sounds you answered today against the sounds still due, with the group chips below it. After each answer the result card shows the correct syllable, your wrong answer, the sound you confused it with, and all tones of the syllable to play back.

## Mnemonics

- **Hanzi Movie Method mnemonics.** For single-character words, a mnemonic scene builder based on the [Hanzi Movie Method](https://www.mandarinblueprint.com/blog/movie-method/) helps you memorize characters. It maps pinyin initials to **actors**, finals to **locations**, tones to **rooms**, and radicals to **props**. Configure your personal library at `/mnemonics`. The page has one tab for each part (Actors, Locations, Tone rooms, Props). Each tab shows how many entries you have filled in, for example `12/23`. Actors stay grouped by category (male, female, fictional, wildcard). Every entry saves when you leave the field. Compose scenes in the vocabulary edit form. Saved scenes appear automatically during training: expanded on wrong answers, and collapsed on correct answers. The app remembers your choices globally, so setting an actor for "b" once pre-fills it everywhere. You can also write mnemonic scenes for component characters (radicals and sub-parts) on the component edit tab of the `/vocab` page. Component quiz result cards show these scenes the same way as word scenes.

## Settings

Each user has a personal settings page (`/settings`) with these sections. Every section below saves automatically as you change a field — there's no Save button. Change Password and API Keys are the exception: both require an explicit action since they touch credentials.

Save confirmations and error messages appear as a small hovering toast in the bottom-right corner, rather than an inline message on the card you edited — so the page never jumps as one is shown or dismissed. It auto-dismisses after a couple of seconds. Saving multiple cards in quick succession doesn't stack up separate messages: the toast replaces its own text and restarts its timer, and if the same message repeats while it's still visible, it appends a "(×N)" counter so each save still registers.

- **Language preferences.** Choose a primary and a secondary language. The app shows the primary language first in the vocabulary list, and uses it as the default quiz language. Both languages are accepted as quiz answers.
- **Training mode.** Customize the quiz format for each proficiency tier, for progressive mode, and for each step in the new-word introduction phase. This section includes "Blur pinyin until tapped", "Celebrate bucket changes" (a level-up interstitial when a word's accuracy tier advances), and "Sentence fill-in-the-blank" with a frequency percentage, under Quiz Display, and the Off / Only what was tested / Chinese and translation choice under Wrong Answer Retry.
- **Cycle mode.** Configure the direction sequence (2 to 7 steps) used by the Cycle quiz mode. Choose whether the cycle advances on every attempt (the default), only after a correct answer, or only when the answer was correct on the first try (no prior wrong guess in that encounter).
- **Random / Cycle Mode by Bucket.** Restrict which quiz formats Random and Cycle mode may pick, per accuracy tier. See [Random / Cycle mode by bucket](scheduling.md#random--cycle-mode-by-bucket).
- **Daily Learning.** Set the number of new words per day, set a cooldown between new-word introductions, toggle the skip button for new words, and toggle session extension (which serves an extra not-yet-due word at the end of a session instead of repeating one right away). You can also configure baseline gates (due-today, struggling, learning, new bucket, accuracy, words that failed their last review) that pause introductions when the review load is high, and the number of failed reviews in a row after which the [leech warning](scheduling.md#lapses-and-leech-words) shows.
- **Gamification.** Enable a word-matching mini-game that appears during training. Configure how often, in minutes, the game may interrupt training. When the game triggers, it shows a Chinese column and a shuffled translation column. Each translation box shows only its first meaning (or its first two, if both are short) rather than a word's full dictionary gloss, and skips example-sentence/measure-word entries (`Bsp.:`/`CL:`/`ZEW:`) the same way training does. The game also skips a translation that is only a phrase in brackets, for example "(Partikel, der ein vorgezogenes, direktes Objekt kennzeichnet)". If a word has no other translation, the game does not use the word. The game shows inline in the training card column. Click a Chinese word and its translation, in either order, to match them. Correct pairs turn green, and wrong pairs flash red. A progress row and a mistake count show above and below the tiles; *Skip round* ends the game early, and a finished round shows a "Round complete" summary before training continues. If a word shares its translation text with another still-unmatched word, claiming that word's box alone does not complete the match. Instead, the box flashes yellow, so you cannot claim it out from under the word it actually belongs to. Exception: when two boxes show exactly the same text (for example 帮忙 and 帮助, both "Hilfe"), either box is correct for either word. The game updates SM-2 progress for each matched word.

  Four game modes supply the words for a round, each with its own on/off toggle (all enabled by default):
  - **Mismatch** — recently confused word or hanzi-component pairs (needs at least 2 confusion pairs from the last 7 days). A pair is suppressed after being shown until it is confused again.
  - **Newest words** — drawn from your 30 most-recently-added words, picked with a weighted random selection that favors more recently added words.
  - **Hardest words** — your lowest-accuracy words (same ranking as the "flag hardest words" drill).
  - **Last mistakes** — words you've recently answered wrong.

  After a word is shown in a round of any mode, no mode shows it again until you answer it wrong in normal training. A correct answer alone does not bring it back. For the Mismatch mode, a new confusion of a pair counts as a wrong answer for both words of the pair.

  When the game triggers, it picks uniformly at random among your enabled modes that currently have enough eligible words, and falls back to another enabled mode if the first pick comes up short.

  A **"Hide pinyin hint once a word reaches"** setting (default **Practicing**) picks the minimum accuracy bucket — New, Struggling, Learning, Practicing, or Mastered, the same buckets used elsewhere in the app — at and above which a word's tile stops showing its pinyin under the hanzi up front, so the game gets harder to rely on rote pinyin recall as you improve. Words below the chosen bucket keep showing pinyin immediately, as before, unaffected by the setting below.

  An **"After selecting a pair, show pinyin"** setting controls whether and when a *hidden* word tile's pinyin hint gets revealed once you've selected both halves of a pair: **Off** (never revealed), **Always** (revealed once that pair is attempted, whether the match was right or wrong — the default), or **Only after correct match** (revealed only once you correctly match that pair). This only affects tiles hidden by the setting above — a word already showing its pinyin from the start keeps doing so regardless. Component tiles (radicals, in Mismatch mode) always show their pinyin from the start too, since they aren't tiered and are never hidden.

  A **"Match-game answers change training progress"** setting controls which matches in the game count as a training answer for the word or component (its SM-2 progress): **Never** (the game is practice only), **Only wrong answers** (a wrong match counts as a wrong answer, a correct match changes nothing), or **Always** (every match counts — the default). Word tiles and component tiles use the same setting. The "Round complete" screen's note adapts to this setting, and a **"Show round summary after the match game"** toggle (on by default) lets you skip that screen so training continues right away.
- **API keys.** Store a personal DeepL API key and an LLM provider key (OpenAI, Anthropic, Gemini, or a local OpenAI-compatible server). The app encrypts these keys with a key derived from your login password, using PBKDF2-SHA256 and AES-GCM, and makes them accessible only while you are logged in. Users with a personal key can use DeepL translation and LLM scene generation without a plus account. A user-supplied local LLM URL must be a public `http(s)` address. The app rejects and blocks internal, loopback, and link-local targets, to prevent server-side request forgery. If you run a trusted local model on loopback, configure it with the server-side `LOCAL_LLM_URL` environment variable instead.

## Self-hosting

- User accounts with registration and email verification. See [Configuration](configuration.md#accounts-and-authentication).
- Leaked passwords are not accepted when you create an account or change your password. A login with a leaked password shows a warning with a link to change it. See [Leaked passwords](configuration.md#leaked-passwords-have-i-been-pwned).
- The app stores its SQLite database on the host filesystem.
- The app runs in Docker or natively. The static frontend is embedded in the Go binary, so the app needs no Python or other external tools.
- Deploy to a Raspberry Pi with `make release` (see [Self-hosting](self-hosting.md#deploy-to-raspberry-pi)). This target cross-compiles for `linux/arm64` and rsyncs the binary over SSH.
