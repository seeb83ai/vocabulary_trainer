## What to build

`hanzi_decomposition_translation` is global, so the component-translation editor (wired
into `vocab.js:372,1767` as an everyday user action) lets any user overwrite radical
definitions for everyone. Scope edits per-user with a copy-on-write overlay over the
shared seeded defaults.

Covers plan item 4.5. (Decision: per-user overlay, NOT admin-only — admin-only would
break a normal user feature.)
